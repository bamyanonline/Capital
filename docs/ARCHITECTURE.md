# CAPITAL Architecture

## Source of truth
- `frontend/` is the canonical frontend source.
- `admin/` is the canonical admin source.
- `backend/worker.js` is the Cloudflare Worker/API source.
- `backend/migrations/` is the canonical D1 schema history.
- `backend/public/` is the deployable static-artifact copy generated by `npm run sync:public`.

Never edit `backend/public/frontend` or `backend/public/admin` directly. Edit the canonical source and run `npm run sync:public`.

## Cloudflare runtime
- Worker: `backend/worker.js`
- D1 binding: `DB`
- Static assets: `backend/public`
- Scheduled job: configured in `backend/wrangler.jsonc`

## Data authority
Financial balances, deposits, withdrawals, referral rewards, profit calculations, permissions and security decisions are server-authoritative. Browser storage is not a financial source of truth.
