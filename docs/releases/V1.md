# CAPITAL v1 Release

This release is the consolidated production-oriented package.

## Frontend
- Single live backend as the source of financial truth.
- Instant language switching without page refresh.
- Frontend languages: English, French, Russian, Chinese, Spanish, Arabic, Urdu, Persian.
- All displayed numeric digits are normalized to ASCII/English `0-9` regardless of selected language.
- No browser financial storage adapter and no inspection/preview route.
- Market snapshot is requested through the same-origin Worker; live Binance ticker support remains explicitly allow-listed by CSP.

## Admin
- Exactly two languages: English and Persian.
- Instant language switching without page refresh.
- Server-side role/permission enforcement.
- Dynamic users, deposits, withdrawals, ledger, activity, plans and KYC data.
- No hard-coded demonstration records.

## D1
- Migrations 0001 through 0007 apply cleanly to an empty SQLite-compatible database.
- Foreign-key check passes.
- Inspection access is seeded in migration 0007 using PBKDF2 only.

## Deployment
- Replace the D1 `database_id` placeholder in `backend/wrangler.jsonc` with the real Cloudflare D1 database ID.
- Create the private R2 bucket named by the Wrangler binding before enabling KYC document storage.
- Configure production secrets outside Git.
- Connect the real TRON/TRC20 verification and withdrawal signing/broadcast provider before real-money operation.
